# OPULENZA

OPULENZA is a responsive estate agent client-side web application built with React and Vite. The application allows users to search and view property listings, inspect individual property details, and manage a favourites list.

## Live Demo

https://opulenza-rust.vercel.app

## GitHub Repository

https://github.com/SteffaniSilva/OPULENZA

## Project Overview

This project was developed for the **5COSC026W Advanced Client-Side Web Development** coursework. The aim of the project is to create a responsive single-page application for searching property listings using client-side React functionality.

Users can search properties using different criteria such as property type, price range, bedroom range, date added, and postcode area.

## Features

- Responsive single-page React application
- Property search by:
  - Type
  - Minimum and maximum price
  - Minimum and maximum bedrooms
  - Date added
  - Postcode area
- Property results displayed with images, descriptions, and prices
- Individual property detail pages
- Image gallery with property photos
- React tabs for property description, floor plan, and map
- Add properties to favourites
- Remove properties from favourites
- Clear favourites list
- Responsive layout for desktop and smaller screen sizes
- Client-side JSON data
- Jest tests for key components
